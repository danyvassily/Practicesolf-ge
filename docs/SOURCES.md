## Gammes implémentées

Intervalles ascendants en demi-tons depuis la tonique, octave finale incluse :

- Majeure : 0, 2, 4, 5, 7, 9, 11, 12.
- Mineure naturelle : 0, 2, 3, 5, 7, 8, 10, 12.
- Mineure harmonique : 0, 2, 3, 5, 7, 8, 11, 12.
- Pentatonique majeure : 0, 2, 4, 7, 9, 12.
- Pentatonique mineure : 0, 3, 5, 7, 10, 12.
- Blues mineure : 0, 3, 5, 6, 7, 10, 12.
- Dorienne : 0, 2, 3, 5, 7, 9, 10, 12.
- Mixolydienne : 0, 2, 4, 5, 7, 9, 10, 12.

Les regroupements « Classique », « Blues » et « Jazz » facilitent la découverte ; ils ne signifient pas qu’une gamme appartient exclusivement à un genre.
